# ✍️ Blog Application — Built by Usman Ahmad

A modern **Blog Platform** built with **React** that allows users to explore blogs, manage their profile, and interact with content through likes and favourites.

This project focuses on **clean component architecture**, **scalable layouts**, and **real-world React routing patterns**.

---

## 🌟 Project Overview

This Blog Application demonstrates how a real content-based platform works:
- Users can browse blogs
- Authenticate themselves
- Manage their own profile
- Edit, like, and favourite blog posts

The goal of this project was to strengthen my skills in:
- React component structuring  
- Layout-based routing  
- User profile management  
- Scalable frontend architecture  

---

## 🚀 Core Features (Already Implemented)

- 📝 Create, edit, and manage blog posts  
- 💬 **Comment system** on blogs  
- ❤️ Like and ⭐ favourite blogs  
- 👤 User authentication & profile dashboard  
- 🧭 Layout-based routing with protected pages  
- 🗄️ **MySQL database integration**  
- 🔗 Frontend ↔ Backend API communication  
- 📱 Responsive and clean UI
